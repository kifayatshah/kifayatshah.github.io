A professional personal portfolio website for **Kifayat Shah**, a

## 🚀 Run Locally

Because this is a static website, no installation is required.

### Option 1 --- Open directly

Open `index.html` in any modern web browser.

### Option 2 --- Use a local server

Using Python:

``` bash
python -m http.server 8000
```

Then open:

``` text
http://localhost:8000
```

## ☁️ Deploy with GitHub Pages

1.  Create a GitHub repository.

2.  Upload `index.html` and `README.md`.

3.  Go to:

    **Settings → Pages**

4.  Under **Build and deployment**, select:

    -   Source: **Deploy from a branch**
    -   Branch: `main`
    -   Folder: `/ (root)`

5.  Save the settings.

GitHub will provide a public portfolio URL.

## 🎨 Design Concept

The visual language of the website is inspired by transportation
engineering:

-   **Signal indicators** represent traffic-control systems.
-   **Route-line elements** represent transportation networks.
-   **Highway and intersection imagery** provide visual context.
-   The structured timeline resembles a transport route/log.
-   Green, amber, and red accents reference traffic-signal systems.

The objective is to make the website immediately communicate
**transportation engineering and ITS**, rather than looking like a
generic developer portfolio.

## 📱 Responsive Design

The layout is designed to adapt to:

-   Desktop screens
-   Laptops
-   Tablets
-   Mobile phones

Navigation, project cards, skills, and contact elements adjust for
smaller screens.

## 🔧 Customization

Most personal information can be updated directly inside `index.html`.

Useful sections to edit include:

``` html
<!-- HERO -->
<!-- EXPERIENCE & SELECTED PROJECTS -->
<!-- EDUCATION -->
<!-- SKILLS -->
<!-- CERTIFICATIONS -->
<!-- LANGUAGES -->
<!-- CONTACT -->
```

The visual theme can be modified through the CSS variables near the
beginning of the file:

``` css
:root {
  --bg: ...;
  --text: ...;
  --green: ...;
  --yellow: ...;
  --red: ...;
}
```
